# TechMind

API REST desenvolvida em Spring Boot para classificação de conteúdos técnicos utilizando Inteligência Artificial.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok

## Executando

1. Criar o banco:

```sql
CREATE DATABASE techmind;
```

2. Configurar as variáveis:

```
DATABASE_USERNAME
DATABASE_PASSWORD
```

3. Executar a aplicação.
